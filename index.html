Waiting for a rampage chain.
Use RCH with AAA, BBB, CCC. Start with !startchain.

CH uses numbers (GG 001 CH -- Tank). Rampage uses RCH and letters (GG AAA RCH -- Tank). !take takes the next free CH number. !take 001 and !skip 001 go to CH; !take AAA and !skip AAA go to rampage. Add a name to place someone else: !take 001 Portlia or !take Portlia. Bare !skip / !back apply to every chain you are on. !startchain and !stopchain start and stop CH and rampage together.
